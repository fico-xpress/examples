Xpress Examples package for Windows
-----------------------------------


We recommend that you unzip this package into the directory referenced 
by the XPRESSDIR environmental variable. This is usually C:\XpressMP.


The examples in this package are grouped by product. Under each product 
directory you will find the examples for that product arranged in 
subdirectories according to the source code language and functionality 
being demonstrated.


For those examples which require compilation, a makefile is provided in 
the relevant subdirectory which is compatible with nmake.

Simply navigate to the subdirectory in question from a console and run 
nmake to build all the examples in that subdirectory.

The examples in this package are fully compatible with the latest Xpress 
release.

Most of the examples will run with older versions of the software.


If you find any errors in the examples please contact FICO
