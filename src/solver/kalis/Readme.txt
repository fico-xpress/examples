Xpress Kalis Mosel examples directory
=====================================

The examples of the Xpress Kalis module for Mosel are contained in the 
following subdirectories:


Features:   Basic examples of Xpress Kalis functionality, with
            listings in the `Xpress Kalis Mosel Reference Manual'. 

UG:         Examples described in the `Xpress Kalis Mosel User Guide'.

Apps:       Some larger examples.
